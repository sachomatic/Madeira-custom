## Answers / notes
- **libc++ pitfall (found 2026-10-14, fixed in the clang shim):** clang-20 from apt searches `/usr/lib/llvm-20/include/c++/v1` (Linux libc++ with a different `__config_site`) BEFORE the iOS SDK, so every C++ object built for iOS used the wrong headers (and `-fmodules` failed). `ios-clang++` now passes `-nostdinc++ -isystem $IOS_SDK/usr/include/c++/v1`. Anything C++ built before that fix (LLVM libs, DXMT, FEX) was rebuilt. C-only libs (wine unix libs, gnutls, ffmpeg, freetype) are unaffected.
